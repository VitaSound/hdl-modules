# Как открыть сессию

Не вставлять старый чат. Не читать весь репозиторий и не читать весь MIT.

```text
Начни с docs/portfolio/NOW.md и следуй ему.
Не читай весь репозиторий.
Один текущий issue до артефакта.
В конце обнови NOW.md, DEVICES.md и допиши 5 строк в JOURNAL.md.
```

Ритуал человека:

1. Открыл [NOW.md](NOW.md).
2. Сделал **один** issue до артефакта.
3. Дописал 5–10 строк в [JOURNAL.md](JOURNAL.md).
4. Обновил статус в [NOW.md](NOW.md) / [DEVICES.md](DEVICES.md).
5. Закрыл сессию.

Если нужно сменить устройство: сначала строка в JOURNAL, зачем, потом правка `current_device` в NOW.md.

Декомпозиция устройства — шаблоны MIT (`docs/templates/project-request.md`, `issue-template.md`); результат класть в `docs/portfolio/devices/<id>.md`, не плодить второй backlog.

OpenSpec в этом репозитории — на поведение модуля, не на всю линейку.
