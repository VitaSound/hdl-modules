## P1. Экосистема сборки (один раз)

Общий тракт для всех устройств:

```text
вход / preamp → АЦП/кодек → цифровой поток
→ обработка / маршрутизация (HDL)
→ ЦАП → выход
+ MIDI/USB + панель + Forth / J1
```

Слои (MIT ADR-0003): листовой RTL в этом репозитории; fhdlgen собирает top; fsoc — плата, Quartus/Verilator, прошивка J1.

Не ждать генерации тел `adsr`/`dds` из Forth. Инстансы top уже умеет fhdlgen 0.4.1; fsoc 0.1.1 мигает LED в эмуляции.

Не считать P1 закрытым только по эмуляции blinky. Нужен LED/UART на EP4CE10 **или** явная запись в [JOURNAL.md](JOURNAL.md), почему кремний отложен.

**Ворота:** `NOW.md` говорит «можно открывать карточки устройств»; `make test` зелёный; VST слышит хотя бы один synth; smoke на пине или запись в журнале.

## P2. Все девять — только виртуально

У каждого устройства: карточка в `devices/`, RTL или явный top, слуховой прогон в DAW. Серийную PCB не начинать. Порядок — от готового к трудному; эталон — `sub` (`mono_synth`).

DoD одного устройства — в [DEVICES.md](DEVICES.md).

**Ворота:** все девять `virtual: done`.

## P3. Железо

Один стенд (EP4CE10 + аудиодочка + MIDI) через `fsoc/projects/<device>`. Не девять ручных Quartus-проектов и не девять PCB, пока три устройства не ожили на одном стенде.

**Ворота:** чеклисты железа в карточках закрыты хотя бы для трёх устройств на общем стенде; остальные — по тому же стенду.

## P4. Внешний вид

Панель, корпус, шелкография — только после работающего железа.

## P5. Мелкие партии
